# xsreality/homebrew-tap

```bash
brew install xsreality/tap/claude-deja-vu
```

- **claude-deja-vu**: [Claude Déjà Vu](https://github.com/xsreality/claude-deja-vu), one searchable view of your Claude Code conversations. A cask, so `DejaVu.app` installs into `/Applications` where Spotlight and Launchpad find it. Ad-hoc signed, so the first launch needs System Settings > Privacy & Security > "Open Anyway".
